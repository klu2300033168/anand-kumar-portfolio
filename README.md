# Anand Kumar — Portfolio Website

A responsive, blue-themed personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — layout and styling
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html` in a text editor.
2. Replace `YOUR_EMAIL@example.com` with your real professional email.
3. Replace the LinkedIn and GitHub profile links with your own URLs.
4. Replace each `https://github.com/` project link with the actual project repository/demo URL, or remove the link if you do not have one.
5. Check the exact names of your certificates and update the Certifications section.
6. Review all project descriptions so they accurately reflect what you personally built.

## Preview locally
Double-click `index.html` to open it in your browser.

## Publish with GitHub Pages
1. Create a **Public** GitHub repository named `portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root (not inside another nested folder).
3. Commit the uploaded files.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. After GitHub Pages finishes publishing, your site will be at:
   `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`

The website link will only work after you publish it.
